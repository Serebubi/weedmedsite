# Maxyield Farm Landing

Standalone premium organic cannabis farm and dispensary landing page for Pattaya / Jomtien.

## Files

- `index.html` - main landing page
- `styles.css` - visual system and responsive layout
- `script.js` - header, contact widget, and 21+ age gate
- `privacy.html` / `terms.html` - simple legal pages
- `assets/images/` - local optimized site imagery

Open `index.html` directly or serve the folder with a static server.
